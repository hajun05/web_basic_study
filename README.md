# web_basic_study

웹 개발 기초를 학습하며 작성한 코드와 예제를 모아 두는 저장소.

강의, 문서, 문제 풀이 등 출처에 구애받지 않고 학습한 내용을 자유롭게 정리. 
완성된 서비스보다는 개념을 직접 구현해 보는 목적.

## 기술 스택

- [Next.js](https://nextjs.org) (App Router)
- React
- TypeScript

## 학습 내용

`app/test` 폴더에서 다루고, 주제는 계속 추가될 예정.

## 실행 방법

```bash
npm install
npm run dev
```

[http://localhost:3000/test](http://localhost:3000/test)에서 확인 가능.
